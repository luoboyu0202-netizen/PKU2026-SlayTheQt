🧗‍♂️ Slay the Qt 
欢迎来到 Slay the Qt 的开源代码库！这不仅仅是一个基于 C++ 和 Qt 框架构建的卡牌游戏项目，这是一封写给神作《杀戮尖塔》（Slay the Spire）的极客情书！

如果你喜欢精妙绝伦的卡牌构筑（Deck-building）、让人绞尽脑汁的遗物联动、以及在丝血反杀 Boss 时那种肾上腺素飙升的快感，那么请立刻拉取这个项目！我们用最纯粹的 C++ 面向对象架构，硬核重现了那座令人疯狂的高塔！

🌟 为什么你必须试试这个项目？
老实说，在 Qt 里写应用不难，但在 Qt 里写出一个果汁感（Juiciness）爆棚、底层逻辑严丝合缝的肉鸽卡牌游戏，绝对是一场疯狂的实验！

🃏 原汁原味的卡牌构筑： 完美复刻了抽牌、弃牌、消耗（Exhaust）和能力（Power）牌系统。不管你是喜欢“黑暗之拥”的无限过牌流，还是喜欢“恶魔形态”的纯粹暴力，底层的 CardManager 都能完美接管你的出牌逻辑！

⛩️ 令人欲罢不能的遗物系统： 游戏内已实装 18+ 种机制完全不同的神级遗物！

喜欢跨回合存费的冰淇淋？有！

想要念珠手镯在小怪战双倍掉落的快乐？有！

就连鸟居的削减微小伤害、钨合金棒的真实伤害拦截，底层 BattleEngine 都做了完美的拦截结界！这可是货真价实的 3A 级结算架构！

👻 压迫感拉满的史诗级怪物： 别以为这里的怪物只是木桩！我们为你准备了拥有完美极坐标冥火法阵的六火亡魂（Hexaghost）！它会根据你的血量动态计算“分界线”伤害，甚至在 6 回合循环后释放毁天灭地的地狱火！

🏕️ 沉浸式的大地图与事件： 物理拖拽的大地图卷轴、充满随机性的问号沙盒事件、以及可以休息回血或锻造升级卡牌的动态篝火（带有绝美的贝塞尔曲线烟雾粒子特效）！

💥 极度丝滑的 UI 演出： 谁说 Qt 不能做酷炫特效？

战利品掉落时的 Q 弹抛物线与星尘拖尾！

怪物受击时的剧烈屏幕震动与死亡消散滤镜！

商店购买时的动态流星入账动画！绝对让你的每一次点击都爽快无比！

🛠️ 技术栈与底层架构 (For the Geeks)
作为由几位热爱编程的爬塔玩家共同打造的课设项目，我们为它注入了极其优雅的底层设计：

核心语言：C++

开发框架：Qt (Widgets / Graphics View Framework)

架构亮点：

“天道户口本”同步机制：通过全局单例 GlobalSaveData 彻底分离“面子账（UI）”与“里子账（逻辑）”，从根本上杜绝了商店购买、宝箱掉落时的遗物覆盖 BUG。

时序钩子大满贯：BattleEngine 采用了极其严谨的事件流，从 onBattleStart 到 onTurnStart，再到 modifyIncomingDamage，多态架构让你轻松拓展无数种新卡牌和新遗物。

沙盒化事件引擎：EventLauncher 为所有问号事件提供安全的隔离环境，战斗结束和事件结束无缝切回大地图频道。

🚀 如何开始你的爬塔之旅？
准备好失去你的睡眠了吗？跟着以下步骤启动游戏：

环境准备：确保你的电脑上安装了 Qt Creator 及其对应的 C++ 编译工具链（支持 C++ 11/14 及以上）。

克隆项目：

Bash
git clone https://github.com/your-username/SlayTheQt.git
打开工程：在 Qt Creator 中双击打开 SlayTheQt.pro（或 CMakeLists.txt，取决于你们最终的构建系统）。

编译运行：点击左下角的绿色三角形（Run），一秒钟后，那座充满挑战的尖塔就会在你面前拔地而起！
